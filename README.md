# Google Search Ranking & Discoverability Capstone

## Research Question
Which page-level features are most associated with stronger Google search rankings?

## What this project contains
- `index.html` — deployable research paper for GitHub Pages
- `notebooks/capstone_analysis.ipynb` — analysis notebook
- `submission/paper_url.txt` — required deployed-paper URL file
- `data/` — place your dataset here

## Quick setup

1. Put your CSV or Parquet dataset inside the `data/` folder.
2. Open `notebooks/capstone_analysis.ipynb`.
3. Change `DATA_PATH` to your real dataset filename.
4. Run all cells.
5. Copy the notebook's printed results into the Results section of `index.html`.
6. Push this project to GitHub.
7. In GitHub: **Settings → Pages → Deploy from branch → main / root**.
8. Copy your live GitHub Pages URL into `submission/paper_url.txt`.

## Important
Do not publish private client names, private URLs, credentials, private queries, or raw confidential exports.

The notebook is designed to adapt to common ranking-dataset column names and will tell you what to change when your column names differ.
