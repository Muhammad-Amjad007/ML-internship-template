Page-Level Features Associated with Google Search Rankings

Google Search Ranking & Discoverability Capstone

Research question: Which page-level features are most associated with stronger Google search rankings?

Abstract

This study investigates which page-level content and structural features are associated with stronger Google search rankings. Using the provided warehouse dataset, the analysis evaluates available numerical features such as content length, title length, headings, internal links, and other measurable page characteristics. The workflow combines data cleaning, correlation analysis, and a Random Forest model to identify features most strongly associated with search position. The findings are intended to support repeatable SEO prioritization and should be interpreted as associations rather than proof of causation.

Introduction and Problem Statement

SEO teams often need to decide which pages deserve attention first and which measurable page characteristics are linked with better organic visibility. This capstone builds a repeatable analysis that ranks page-level signals by their relationship with search position. The goal is not to claim that any single feature causes a ranking increase, but to identify useful patterns that can guide testing and content improvement decisions.

Methodology

  1. Load the approved CSV or Parquet dataset.
  2. Identify the search-position target column.
  3. Select numerical page-level features and remove unusable or highly incomplete fields.
  4. Clean missing values using median imputation.
  5. Calculate correlations with ranking position.
  6. Train a Random Forest regressor as a repeatable baseline model.
  7. Rank features using model feature importance.

Ranked Recommendations

  1. Prioritize pages where the strongest observed feature gaps coincide with weak search positions.
  2. Improve internal linking where the dataset shows a meaningful association with stronger rankings.
  3. Strengthen thin or structurally weak pages only when supported by the observed feature rankings.
  4. Test recommendations incrementally and measure changes over time rather than assuming causation.

Limitations

Search rankings are influenced by many factors that may not be present in the dataset, including backlinks, competition, search intent, technical health, freshness, brand signals, and algorithmic changes. Correlation and model importance do not establish causation. Results may also depend on the quality, coverage, and time period of the available data.
